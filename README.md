## 新项目
### [招聘AI智能体 | 大模型数据闭环实践 （2025年9月，大模型实践）](https://github.com/bingxiao-wcy/Python/tree/master/%E5%A4%A7%E6%A8%A1%E5%9E%8B%E6%8B%9B%E8%81%98%E9%9C%80%E6%B1%82%E5%AE%9E%E8%B7%B5)
#### 🎯 项目背景
在求职准备阶段，每天在牛客/Boss/各大官网来回 30+ 站点，面经/JD/笔经分散、重复率 60%+，人肉检索日均 2 h。为把时间投入刷算法，用 LLM 数据工程思路做“面经+岗位”一站式 Agent，把采集→清洗→评估→提示词优化→产品化串成闭环，沉淀可复用的领域数据资产。

#### ✨ 核心内容
- **数据工程（采集→清洗→评估）**：基于 Python 构建爬虫系统，抓取20+互联网公司招聘JD及面经，实现增量更新与结构化存储。设计质量评分器（规则+语义打分），自动过滤低质/广告帖。基于余弦相似度进行语义去重，重复率由44%降至22%，留存率为34.8%。
- **知识库构建（QA抽取→评估）**：利用正则抽取原始数据，构建QA面经知识库。岗位知识库包含名称、描述、要求等7个字段，直接解析入库。构建多种指标评估知识库的完整性、相似性等，确保知识库质量。
- **agent 搭建（插件→工作流→智能体）**：基于扣子空间，设计并搭建多条智能工作流，集成插件与大模型能力，结合结构化知识库，实现用户问题的精准理解与自动回答，提升系统智能化水平。
- **提示词优化（promote）**：结合用户行为数据，优化提示词设计，运用思维链（Chain-of-Thought）技巧，引导大模型逐步推理，显著提升回答准确性与用户满意度。

#### 🛠️ 技术栈
| 模块         | 核心技术                          |
|--------------|-----------------------------------|
| 数据采集     | Python、Requests                  |
| 数据处理     | Pandas、正则表达式、Simhash、余弦相似度去重       |
| 数据评估     | 6维DQ评分体系（自定义）           |
| 智能体开发   | 扣子（Coze）空间、工作流编排、插件开发 |
| 模型优化     | LoRA模型微调、提示词工程优化           |

#### 📊 项目成果
1. 数据：搭建自动化爬虫与数据处理流程，实现数据定时更新与知识库增量构建。构建高质量面经与岗位知识库，支撑下游问答与推荐任务。 
2. 智能体：依托提示词工程，在已有面经&岗位知识库上打造招聘问答智能体。
3. 产品：整套“领域数据→质量评估→模型微调→Agent 编排”方案封装成模板，可快速迁移到金融、医疗等其他垂直场景，满足企业级 LLM 数据闭环需求。
